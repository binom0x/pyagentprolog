Данный пример демонстрирует создание простого агента, управляющего освещением в помещениях. 
- Агент хранит информацию о состоянии света в комнатах в базе знаний Prolog (картина мира)
- Всё состояние агента хранится **в одном составном терме**, в факте `lights/1`, аргументом которого является список пар `комната-состояние`.
- Агент может изменять картину мира с помощью встроенных предикатов `set_state/1` и `update_state/1`, а также вызывать Python-функции для имитации физического управления устройствами. Для взаимодействия с агентом используются Prolog-запросы.

### Структура примера

1. **Программа на Prolog** – содержит факты о текущем состоянии света и правила для изменения состояния.
2. **Python-действия** – декорированные функции, которые регистрируются как пользовательские предикаты:
   - `physical_turn_light/2` – эффектор, имитирующий обращение к физическому устройству.
   - `get_light_state/2` – простое действие, возвращающее состояние света (например, от датчика).
   - `list_rooms/1` – генератор, выдающий названия комнат.
3. **Инициализация агента** – загрузка Prolog-программы, регистрация действий, выполнение запросов.

### Исходный код

```python
"""
Пример агента для управления освещением (агент-ориентированный подход).
"""
from prolog import Agent, simple_action, effector_action, generator_action

# ----------------------------------------------------------------
# Python-действия
# ----------------------------------------------------------------
@effector_action('physical_turn_light', 2,
                 description="Имитирует физическое включение/выключение света")
def physical_turn_light(room, state, context=None):
    print(f"[PHYSICAL] Свет в комнате '{room}' переключён в состояние '{state}'")

# ----------------------------------------------------------------
# Программа на Prolog (картина мира)
# ----------------------------------------------------------------
PROLOG_PROGRAM = """
% Единственный факт, хранящий состояние всех комнат
lights([(kitchen, off), (living_room, on), (bedroom, off)]).

% Получить состояние конкретной комнаты
light(Room, State) :-
    lights(L),
    member((Room, State), L).

% Обновить состояние комнаты (создаём новый список и заменяем факт lights/1)
set_light(Room, NewState) :-
    lights(OldL),
    update_list(OldL, Room, NewState, NewL),
    set_state(lights(NewL)),          % атомарная замена всего состояния
    physical_turn_light(Room, NewState).

% Вспомогательный предикат: заменить в списке пару для комнаты
update_list([], _, _, []) :- fail.
update_list([(R,_)|T], R, NewState, [(R,NewState)|T]) :- !.
update_list([H|T], R, NewState, [H|NewT]) :-
    update_list(T, R, NewState, NewT).

% Удобные обёртки
turn_on(Room) :- set_light(Room, on).
turn_off(Room) :- set_light(Room, off).

toggle(Room) :-
    light(Room, State),
    (   State = on -> turn_off(Room)
    ;   State = off -> turn_on(Room)
    ).
"""

# ----------------------------------------------------------------
# Инициализация и выполнение
# ----------------------------------------------------------------
def main():
    agent = Agent(program=PROLOG_PROGRAM, context={})
    agent.register_action(physical_turn_light)

    print("=== Текущее состояние света ===")
    result = agent.query("light(Room, State).")
    print(result)

    print("\n=== Включаем свет на кухне ===")
    success = agent.query_one("set_light(kitchen, on).")
    print(f"  set_light выполнено: {success is not None}")

    print("\n=== Проверяем состояние кухни ===")
    state = agent.query_one("light(kitchen, State).")
    if state:
        print(f"  Кухня: {state['State']}")

    print("\n=== Переключаем свет в спальне ===")
    success = agent.query_one("toggle(bedroom).")
    print(f"  toggle выполнено: {success is not None}")

    print("\n=== Новое состояние спальни ===")
    state = agent.query_one("light(bedroom, State).")
    if state:
        print(f"  Спальня: {state['State']}")
    else:
        print("  Факт о спальне не найден! (но это странно, он должен быть)")

    print("\n=== Все комнаты после изменений ===")
    for solution in agent.stream("light(Room, State)."):
        print(f"  {solution['Room']}: {solution['State']}")

    print("\n=== Полное состояние (факт lights/1) ===")
    full = agent.query_one("lights(L).")
    if full:
        print(f"  {full['L']}")

if __name__ == "__main__":
    main()
```

### Пояснения

- **Картина мира** представлена фактом `light/1`. Агент может запрашивать их, изменять с помощью `set_state/1` (замена всех фактов с тем же функтором) или `update_state/1` (добавление без удаления).
- Предикат `light/2` получает состояние конкретной комнаты, работая со списком через `member/2`.
- Обновление (`set_light/2`) читает текущий список, изменяет нужный элемент и вызывает `set_state(lights(NewL))`.
- **Python-действия** регистрируются через декораторы `@effector_action`, `@simple_action`, `@generator_action`. Они становятся доступны как обычные предикаты в Prolog.
- **Контекст** (`context`) позволяет передавать в действия внешние ресурсы (клиенты API, базы данных и т.п.). В примере он не используется, но показан как параметр функций.
- **Методы агента**:
  - `query()` – возвращает все решения запроса.
  - `query_one()` – возвращает первое решение или `None`.
  - `stream()` – генератор для поочерёдного получения решений (полезно при большом количестве результатов).
  - `add_fact()` / `retract_all()` – динамическое изменение базы знаний.
- Встроенные предикаты `set_state/1` и `update_state/1` уже включены в агент и могут использоваться в Prolog-коде без дополнительной регистрации.
